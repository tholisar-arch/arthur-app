# arthur-app — Les aventures de Tracto

Histoires animées et interactives pour Arthur (engins de chantier, dinosaures, copains…),
racontées à voix haute. Faite pour l'iPad : ouvrir le site dans Safari, puis
« Partager → Sur l'écran d'accueil » pour l'avoir en plein écran comme une appli.

Ajouter une histoire : la demander à Claude (voir `CLAUDE.md`).
